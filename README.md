# Clarinet Portfolio

A static website with my performance career and reportoire resources for clarinet

## Website Link
https://dominicvalerio.github.io/ClarinetPortfolio/

## Tech Stack
HTML/JavaScript/Tailwind CSS  - Core structure and dynamic repertoire rendering.

## Features 
- Repertoire Grid: A dynamically generated list of beginner to advanced pieces with technical tags and recording links.

- Performance Timeline: A clean history of my ensemble experience in the Orlando area.

- Responsive Design: Optimized for both desktop and mobile viewing.
