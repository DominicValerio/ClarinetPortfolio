# Clarinet Portfolio

A static website showcasing my performance career and reportoire resources

## About
This site serves as a professional portfolio and resource hub. It highlights my experience with the UCF Symphonic Band and the Florida All-State Symphony Orchestra, while also providing a curated list of essential clarinet repertoire for students and performers.

## Tech Stack
HTML5/JavaScript - Core structure and dynamic repertoire rendering.

Tailwind CSS - Modern, responsive styling via CDN.

IMSLP Integration - Direct links to public domain sheet music.

## Features 
- Repertoire Grid: A dynamically generated list of beginner to advanced pieces with technical tags and recording links.

- Performance Timeline: A clean history of my ensemble experience in the Orlando area.

- Responsive Design: Optimized for both desktop and mobile viewing.
